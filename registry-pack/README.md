# MapAdKiller

高德 / 百度 / 腾讯三家地图的**去广告 + 界面精简** LSPosed 模块（libxposed API 102）。

- 去广告：开屏、横幅、推送、信息流运营卡、第三方广告 SDK 自动检索拦截（三家）
- 界面精简：百度地图首页入口栏/工具宫格/回家去公司/天气/信息流 + 「我的」页
- 高德：首页标签栏 / 工具宫格 / 推荐内容 / 我的页 / 搜索页去广告
- 设置页**左右滑动分页**，按 App 分页互不混排
- 打开自动检查更新（多源回退，国内无代理可用）：镜像下载 / GitHub / Telegram / 稍后更新
