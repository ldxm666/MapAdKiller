# MapAdKiller

高德／百度地图广告精简与界面定制模块，基于 **libxposed API 102**。当前正式版 **2.1.2（版本码 212）**。

[下载模块](https://github.com/Xposed-Modules-Repo/io.github.ldxm666.mapadkiller/releases/tag/212-2.1.2) · [源码及完整交付](https://github.com/ldxm666/MapAdKiller/releases/tag/v2.1.2) · [详细更新公告](https://github.com/ldxm666/MapAdKiller/blob/master/docs/RELEASE-2.1.2.md) · [更新日志](CHANGELOG.md)

## 相比 2.1.0 的主要变化

- **高德首页**：处理刷新回流的营销信息流、天气和榜单，修复面板拖动、回弹及工具重排。
- **高德工具**：补齐步行、骑行，核对“更多工具”目录，增加仅显示已开启工具模式，防止未知下发工具混入。
- **高德底栏**：显示、布局与点击目标同步，修复隐藏打车后误触和按钮背景尺寸。
- **高德地点详情**：独立控制长按地图后的“发现好去处”照片信息流，保留地址和路线操作。
- **百度底栏**：可见按钮与透明代理点击区一起重排，修复“我的”误进入打车。
- **百度搜索**：去除热度飙升榜、推广搜索词和推荐标签，保留常用地址、分类、历史与正常搜索。
- **地图标识**：两个地图均使用整体显示开关，保留道路、城市与基础地理内容；修复百度底图白屏。
- **配置与兼容**：分组导出恢复高德、百度及模块设置，按实际接口能力适配，完善 Vector 2.2 公开服务接口和异步状态查询。

## 安装与范围

覆盖安装 APK，在支持 libxposed API 102 的框架中启用模块及地图作用域。大多数设置为“开启显示、关闭隐藏”，修改后强停对应地图再打开。

本轮主要实测高德 **17.00.0.2005**、百度 **22.0.0（1650）**，Android 16／LSPosed 2.1.1。Vector 2.2 完成公开接口与依赖检查，尚未在该框架实机复测；腾讯沿用原实现，本轮未验证。未知接口回退原应用行为，不承诺所有地图版本已适配。

普通模块 APK 需要框架，免 Root 整合包另行提供。作者：ldxm666。许可证：GPL-3.0-or-later。
