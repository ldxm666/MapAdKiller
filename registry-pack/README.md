## 相比 2.1.0 的主要变化

- **高德首页**：处理刷新回流的营销信息流、天气和榜单，修复面板拖动、回弹及工具重排。
- **高德工具**：补齐步行、骑行，核对“更多工具”目录，增加仅显示已开启工具模式，防止未知下发工具混入。
- **高德底栏**：显示、布局与点击目标同步，修复隐藏打车后误触和按钮背景尺寸。
- **高德地点详情**：独立控制长按地图后的“发现好去处”照片信息流，保留地址和路线操作。
- **百度底栏**：可见按钮与透明代理点击区一起重排，修复“我的”误进入打车。
- **百度搜索**：去除热度飙升榜、推广搜索词和推荐标签，保留常用地址、分类、历史与正常搜索。
- **地图标识**：两个地图均使用整体显示开关，保留道路、城市与基础地理内容；修复百度底图白屏。
- **配置与兼容**：分组导出恢复高德、百度及模块设置，按实际接口能力适配，完善 Vector 2.2 公开服务接口和异步状态查询。

## 安装与范围

安装 Release 中的 MapClean-lsp-v2.1.2.apk，已有用户可覆盖升级。在支持 libxposed API 102 的框架中启用模块，勾选需要处理的地图作用域，再进入模块设置调整开关，修改后强停对应地图并重新打开。

多数“显示……”设置为开启显示、关闭隐藏；标为“关闭……”或“去除……”的设置则是开启去除规则。工具栏总开关控制整个列表，“仅显示已开启工具”开启后只保留明确选中的工具，未知下发工具不自动加入。使用该模式时请先开启工具栏，再选中步行、骑行等所需项；要继续进入完整目录，请保留“更多工具”。

## 功能范围

| 功能 | 高德 | 百度 |
| --- | --- | --- |
| 首页广告与营销流 | 天气、榜单、活动和推荐信息流控制 | 活动、任务横幅、推荐流、AI 此刻控制 |
| 底栏入口 | 列表、布局和点击目标同步 | 可见按钮与原生透明点击区同步 |
| 工具列表 | 步行、骑行、更多工具及仅显示选中工具模式 | 保留现有工具设置 |
| 地点详情照片推荐 | 独立隐藏“发现好去处”，保留地址、周边快捷工具与路线 | 本轮未新增详情推荐清理 |
| 搜索推广 | 保留现有搜索设置 | 热度飙升榜、推广词和推荐标签清理 |
| 底图兴趣点 | 整体显示开关，保留道路及城市名称 | 整体显示开关，保留道路及城市名称 |

地图兴趣点默认隐藏；搜索结果、收藏点、选点与导航提示可能作为独立业务图层继续显示。高德地点详情开关默认隐藏照片信息流，不清空地址和路线操作。

## 配置与升级

升级前建议导出配置。设置中的“保存配置／恢复配置”用于本地备份，“更多 → 导出／导入”用于 JSON 配置交换，覆盖高德、百度及模块设置。旧版仅含高德的配置可继续导入，缺失的百度设置不会被重置；旧地图标识分类会迁移为整体开关。导入后强停地图重开。

备份不包含地图账号、收藏、离线地图或框架作用域，更换设备时需重新勾选地图。发布 APK 与自行构建 APK 若签名不同，无法直接覆盖安装。

本轮主要实测高德 **17.00.0.2005**、百度 **22.0.0（1650）**，Android 16／LSPosed 2.1.1。Vector 2.2 完成公开接口与依赖检查，尚未在该框架实机复测；腾讯沿用原实现，本轮未验证。未知接口回退原应用行为，不承诺所有地图版本已适配。

**本轮不发布免 Root 整合 APK**；当前下载是需要兼容框架的普通模块。

## 常见问题与反馈

开关不生效时，先检查框架启用状态及作用域，再强停地图重开。工具显示还受工具栏总开关和“仅显示已开启工具”共同影响。Vector 的等待连接、作用域读取失败和未勾选地图分别显示，不能将等待服务直接理解为未激活。

刷新广告回流或底栏跳错页面仍可复现时，请在 [项目 Issues](https://github.com/ldxm666/MapAdKiller/issues) 提供模块、地图、Android、框架版本，相关开关状态与完整操作步骤。高德“其他”页和百度“诊断”可开启日志，复现后提取相关框架日志并关闭日志；公开前遮挡账号、精确位置、路线、订单及令牌。
