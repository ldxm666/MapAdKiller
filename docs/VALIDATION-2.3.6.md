## 过程中的失败与修正

build-tools 37 的签名解析结果不可靠，本轮固定使用 35.0.0 并重新验证。百度 APK 的 ZIP 目录 / 本地标记差异经载荷一致性检查后修复。UI 拖动测试曾因系统拖动窗口的注入方式和焦点 / 坐标时机失败，修正测试驱动后真实拖动通过。重型宿主反射探针曾被系统终止，相关接口改由实际 DEX 验证：LLM start 回调入口返回 String，未把旧探针的 void 假设当成生产缺陷。视图树探针的内部 shell 等待也已改为原生 Intent 启动。

这些过程性失败不计入最终通过次数。最终自动结果见 validation-2.3.6-results.json，完整生产报告、成品审计及各包验证报告随测试包交付。
