## 3. 已完成的修复与关键原因

### 高德 Play 与首次加载

- 按实际原包 DEX、方法签名及调用关系适配。Play 请求类／广告数据为 `ys5`／`fj6`，国内版为 `ah5`／`k66`；不能只凭“同名类存在”就挂载。
- Context 未就绪时不再长期缓存临时默认配置，宿主就绪后重读用户保存值。
- 适配结论只针对上表宿主基线，不代表未来 Play 新版也有效；新版本必须重新取包核对。

### 首页工具、排序与面板恢复

- 模块设置页与内置面板共用排序组件：长按拖动、上移／下移，即时保存。按工具 ID 存储，关闭保留位置、新工具追加，恢复默认只清排序；“更多工具”固定末尾。
- 天气首页 `QuickServiceRedesign.page.js` 实际通过 `recommendTools` 读取工具。原代码只删旧推荐、不补已开工具，所以曾经一直只显示两项加“更多工具”。现在补齐完整宿主工具对象，先选择、排序，再限量；名称、图标与跳转一起移动。
- 同页的 `choiceTools` 是“更多工具”文件夹预览，不能把同一工具列表同时填进两边。严格限定首页清空预览，修复拼图图标和公交角标；其它页面和宿主原选择不改。
- **AJX 推荐列表最多九个普通工具。** 原生先保留“更多工具”槽位，关闭它时仍保留九项，不能再塞第十个形成十一单元模型。超出首页容量的工具可通过排序移到前面。
- `AmapHomeTools` 只定位限定 DOM 的真实绑定，忽略过期绑定；单独关闭“更多工具”或关闭工具总开关时回收相应占位，重新打开恢复。
- 原生结束 AJX 渲染会移走工具面板。`AmapNativeHome.restoreNativePanel` 通过已核对的 `initToolBoxPanel` 接回脱离面板，保留隐藏／拖动状态与父容器归属，不重复添加、不抢其它页面控件。
- 首页工具仅改显示副本，对应写回入口有保护，不能把补齐后的列表污染到宿主原始选择。临时诊断类 `AmapMoreDom` 已删除，不应重新打进包。

### 内容卡片与推广

- 用户最终要求是 **两个可见开关**：`feed_weather` 天气卡片；`feed_other` 推荐与活动卡片。后者合并原榜单、攻略／内容流、促销三项，不要按早期计划重新拆成四个可见开关。
- `FeedCardConfig` 统一读取与旧备份迁移：新值明确保存后优先，未设置时 OR 兼容原三个值。不能预先落盘默认 false 掩盖旧设置。打车、家／公司入口仍独立。
- 流式分类保留序号、结束信号和地图数据，防止被隐藏的前序卡片堵住天气。
- `ridesharerecruit` 招募卡归入活动推广，“发布行程”不随天气放行。
- 右侧圆形扫街榜使用原生 `template_rank` 类型处理，保留普通缩放和图层控件。

### 自动巡航、百度与腾讯

- 新增 `cruise_force_off`“强制关闭自动巡航”，默认 false；开启后优先于两套自动开关，清理待执行任务、重试和累计条件，保留手动巡航与正常导航，不强退已经开始的巡航。
- `AmapCruiseOfficial` 用线程内上下文保留最外层原始请求，避免嵌套重放将模块改写后的 true 误记为原生请求，导致解除限制后误布防。
- 百度 `BaiduHomeReselect` 沿原生收起／隐藏及回调处理精简首页重复点击白屏，正常内容沿用原生行为。
- 腾讯 `TmapHomeBanner` 清理首页“新人专属”等推广的图片、动画与点击区域，保留独立开关。
- 高德／腾讯已有 POI 业务分类、导航信息栏大小等历史功能继续保留。Kotlin 主源码迁移和设置 UI 重构也是历史功能，不应重复写成下一版新增；Java 桩与测试仍有用途，不要全仓删除 Java 文件。
