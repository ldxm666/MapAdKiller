# 2.1.0-beta1 修复交付说明

交付日期：2026-10-08。模块包名 `io.github.ldxm666.mapadkiller`，versionCode 210，libxposed API 102。

## 高德地图

保留本轮已在手机验证、经用户确认的新实现。适配高德 17.00.0.2005。

- 使用首页原生组件、工具 ID 和信息流协议入口，替代首页遍历及周期扫描。
- 处理天气、扫街榜、出行节、推荐内容、打车营销卡及通勤入口，保留信息流结束状态。
- 修复隐藏工具后的排列、首页上下拖动和底部选中背景；增加好友动态开关。
- 隐藏地图上的扫街榜活动入口。

## 百度地图

以用户指定的 2.0.0 百度部分为基线修复，适配百度地图 22.0.0（1650）。

- 运行入口改用 `BaiduHooks`；旧 `HomeClean`、`MineData`、`MineJs` 和通用 `BmapHooks` 不再安装。
- 改为组件注册、原生 Presenter 和组件绑定入口 Hook，移除百度运行路径中的全局视图扫描及广告 SDK 扫描。
- 配置读取采用缓存；整块及逐项显示开关共用配置规格，剩余底部入口均分宽度。
- 「我的」页仅在已核验 Talos 页面中筛选卡片列表，运营卡与导航车标分别控制；不修改全局数组原型。
- 页面脚本从原始 bundle 生成独立副本；不覆盖原始 bundle。未知页面及未支持版本保留原行为。
- 新增 `BaiduAdHooks`：拦截左上角 V22 活动图标创建、开屏联动入口及恢复显示；拦截任务横幅展示、轮播及恢复显示。

## 验证范围

- 最新 APK 编译、DEX 生成和签名验证成功，已通过 ADB 覆盖安装到连接的手机。
- 百度最新一次安装日志显示 `ok=44 miss=0`；广告入口 Hook 已实际命中。
- 冷启动截图中 V22 活动图标、任务横幅已消失；后续上下拖动及返回首页画面未见这两处广告。
- 当前这轮 AndroidRuntime 日志未见 Java 崩溃。此前页面、滑动和开关行为由用户实机确认通过。
- 此处结果针对上述实测地图版本；不声明其他地图版本或所有服务器下发内容均已验证。

## 安装与构建

已签名 APK 可覆盖当前模块安装；保留 LSPosed 中原有启用状态和作用域，强停目标地图后重新打开。
调整百度开关后同样强停百度再打开，以便重新建立组件及页面脚本。

源码采用仓库的 `app/build.ps1` 构建；依赖 JDK、Android SDK build-tools 和仓库内的 libxposed 编译依赖。
按本机路径调整脚本顶部工具链配置。源码交付不包含签名密钥；首次自行构建时脚本会生成调试密钥。
交付 APK 的签名与当前已安装模块一致，自行构建的签名取决于所用密钥。
