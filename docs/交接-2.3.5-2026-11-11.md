## 4. 高德最新问题的关键原因

这部分依据高德国内 17.02.0.2010、Play 17.02.2.2014 的 DEX 和实机日志确认。再次修改时先核对宿主状态机，不要用全局触摸拦截、持续重排或循环 setter 掩盖问题。

### 4.1 高度输入不等于 getter 返回值

原生 `SlideContainer` 的最小高度、锚点 setter 会额外加入约 10dp 的拖动栏高度；透明区域 setter 会额外加入状态栏高度。直接比较输入值和 getter，会一直误判为高度不一致，继而反复重设面板，导致卡顿、状态恢复失败。

当前 `geometryMatches()` 按原生偏移比较；只有实际几何变化才写入。`AmapHomeGeometry.minimum()` 先验证原生上下两种结构：106dp / 152dp 加系统 inset；结构不匹配时保留原值。不能从未知布局中直接扣固定高度，也不能吞掉系统手势区域。

### 4.2 原生隐藏、拖动与动画状态必须保留

- `resize()` 对 `HIDDEN`、`HIDDEN_EMPTY`、拖动以及原生 drag helper 未空闲时直接放行。
- 只在可见且稳定的 `ANCHORED`、`EXPANDED`、`COLLAPSED` 状态处理调整。
- 原生状态回调先正常执行；宫格可见性随状态恢复，避免关闭再开启后仍保持隐藏。
- 下一帧更新按视图去重；位置正确时不重复写 setter，避免布局循环。

### 4.3 收起后停在中间与额外锚点有关

`finishCompact()` 使用原生私有方法 `computePanelTopPosition(float)` 比较实际位置。通过 `H.method()` 沿类层级查找，不能换成只查 public 方法的 `getMethod()`。仅在面板空闲且位置确实异常时，调用原生 `setPanelState(target, false)` 复位额外锚点；正常位置不重复设置。

已经覆盖的回归包含：开关宫格后只剩搜索框、地图点击全屏及恢复、反复展开收起、中间停留、稳定帧不持续改写几何、保留非工具行的原生视图身份。

## 5. POI 与开屏的适配边界

### 5.1 标注分类

九类为：餐饮、购物、医疗、学校与科教文化、交通、住宿、景点与休闲、金融、生活服务。

- 高德：先打开“兴趣点”总开关，再选择分类；修改后强制停止并重开地图。总开关关闭仍表示全部隐藏。
- 高德分类键为 `map_poi_food` 等九个 `map_poi_*` 项；不应把道路、搜索或路线标记并入业务 POI 过滤。
- 腾讯分类键为 `ui_poi_food` 等九个 `ui_poi_*` 项；在主页运行中应用，搜索、导航恢复原生样式。
- 腾讯样式改动仅写私有副本，保留原文件和原生已禁用项。教学楼按已确认教育图标归类；通用楼宇、混合用途、未知图标仍可能保留，不能承诺所有学校相关建筑都能识别。
- 只看到 “HOOKED” 不能判定有效。腾讯完整模块应同时确认宿主就绪后的实际类加载器、分类入口命中，以及本地诊断报告中的 `poi_categories=native_applied`；该诊断不一定直接出现在 logcat 文本里。

### 5.2 高德开屏

- 国内缓存门控类为 `y96`，Play 为 `wm6`；对应锚点文件分别位于 `tools/anchors-amap-splash-cn-17.02.0.2010.json` 和 `tools/anchors-amap-splash-play-17.02.2.2014.json`。
- 缓存拦截限定在原生展示调用范围，不应影响预加载或 schema 路由。
- R8 可能移除结果类构造函数，生产实现不能依赖反射分配一个假定有构造函数的结果对象。
- 请求拦截需要释放完成回调；不能仅返回而把开屏流程挂起。
- `alimama_splash_off` 缺省开启，但已保存的 false 优先，不能覆盖用户选择。

## 11. 交接 ZIP 怎么用

解压后先读本文件。`source/` 包含从正式发布源码包校验后展开的 422 个项目文件和原始源码清单；`module-repository/` 是模块仓库已发布提交的 9 个跟踪文件快照；`release/` 包含发布状态、附件摘要、安装摘要、模块静态检查和公告命令。

`FILES_SHA256.txt` 校验交接包内的文件，`HANDOVER_MANIFEST.json` 记录提交、来源源码包摘要及内容清单。`release/SHA256SUMS.txt` 则用于核对 GitHub 上的安装包和源码附件，两者用途不同。

交接包不携带约 1GB 的地图安装包；需要安装时从第 2 节正式 Release 下载并校验。源码包已包含项目所需的公开编译依赖及项目 native 库，但不含地图原始 APK、签名密钥、令牌、个人配置和设备抓取数据。
