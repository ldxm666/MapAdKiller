# MapAdKiller 2.3.4

发布日期：2026-11-08 · versionCode **2304** · 对比基线：**2.3.3**。

本次集中修复“开关单独启用无效、关闭后恢复不完整、不同构建行为不一致”等问题。模块版、高德国内内置版、高德 Play 内置版、百度内置版和腾讯内置版同步更新。Kotlin 主源码迁移、设置 UI 重构和导航缩放由 2.3.3 引入，本次延续，不重复作为新增功能。

## 相比 2.3.3 的修复

### 高德国内版与 Google Play 版

- **修复底栏开关无效及切换后白屏的相关路径**：保留原生完整标签模型和控制器，只改变可见入口；恢复标签原有可见状态，不再通过删减模型破坏原生索引与路由。
- 隐藏当前选中的打车或我的入口时，安全返回首页；修正入口 ID 与控制器对应关系，保留再次开启及冷启动行为。
- 首页设置接入统一的配置监听及失效路径，补齐模块 App 修改、批量恢复后已缓存视图不刷新的情况。
- 工具宫格只恢复本模块修改过的原始可见状态，不把宿主原本隐藏的项目强行显示；导航缩放刷新在宿主尚未初始化时安全退出。
- 高德内置包改用标准 ZIP 布局改善“首次安装提示套件无效”的兼容性，包体有所增加。**POCO F3 / MIUI Global 14 / Android 13 尚待该机型安装反馈，不宣称已完成机型验收。**

### 百度地图

- **修复我的页卡片开关相互牵连和单独打开顶部图标宫格无效**：改用页面私有渲染列表，保留原始 `cardList`、服务器数据与页面头部；支持八项子开关组合和页面内恢复。
- 移除旧的共享数据修改与全局数组原型过滤实现；同时适配已取得的旧 `userCenter` 编译模板和新 `userCore` 页面模板，未知结构原样放行。
- 我的页、通勤卡片、工具宫格使用同一配置刷新入口，补齐外部模块配置回调、本地写入及批量恢复的刷新遗漏。
- 底栏隐藏时保留原生点击、触摸监听及触摸代理，仅改变本模块拥有的可见/启用状态；修复重新开启语音入口后无法恢复原生触摸处理的路径。
- Talos 页面脚本与地图样式缓存按实际内容识别更新，不再错信相同文件长度或修改时间。

### 腾讯地图

- 首页快捷入口重新开启时，恢复原生行高和历史行高，通过宿主真实 setter 重新计算布局；恢复失败保留状态以供重试。
- 底栏过滤使用私有列表副本，不原位删除宿主缓存；未知新标签默认保留，防止新入口被误隐藏。
- 底栏、通勤及首页卡片只恢复本模块修改过的原始状态，尊重宿主原本的 `INVISIBLE` / `GONE` 及后续修改。
- **修复 Android 13 上腾讯反射辅助类使用 `java.lang.ClassValue` 导致加载失败**，改用兼容的弱键/弱值缓存，并避免持有宿主类加载器。
- 腾讯底栏逐项入口仍需重新打开地图，让宿主重新绑定；主页标注范围仍包含 POI、路名与地名，不是任意 POI 分类过滤器。

### 共享代码与构建

- native 库提取缓存按 SHA-256 内容识别，校验已有文件内容；覆盖等长更新与等长缓存损坏场景。
- 修复 DEX 锚点工具漏识别构造器、查询失败未明确传播的问题，避免错误的“缺少锚点”或误判通过。
- 增加跨模块回归台账、独立生产 DEX 测试入口及对应缺陷测试；源码包同时包含这些测试及所需编译依赖。

## 验证范围

- 完整模块 **27 组、8599 项检查通过**。
- 解出完整模块及四类内置包中的真实生产模块，在 Android 13 和 Android 16 各执行 60 组，共 **120 组生产 DEX 回归通过**；测试 DEX 与生产 DEX 分离，避免测试副本覆盖生产实现。
- 百度两代真实页面模板分别通过完整模块和内嵌模块适配：四份 JS 运行合计 **9293 项检查通过**；256 种卡片组合、动态恢复、生命周期及原始数据身份纳入回归。
- 高德国内/Play 功能 DEX 一致，宿主补丁和签名分别校验；最终模块及各宿主检查版本、签名、ZIP、内嵌模块和功能裁剪。
- 最终完整模块、国内高德、百度、腾讯在测试手机覆盖安装成功，三个地图正常启动；百度首页与我的连续两轮往返正常，当前开关选择保留。
- 以上不等同于所有官方宿主的外部 LSPosed 注入、全部机型或所有 UI 场景验收。详细证据及边界见 [验证说明](VALIDATION-2.3.4.md) 和 [回归台账](REGRESSION.md)。

| `Baidu-2.3.4-nonroot-embedded.apk` | 百度 22.1.20 内置版 |

| `MapAdKiller-2.3.4-source.zip` | 项目源码及必要编译依赖，不含地图原包、个人配置或签名私钥 |
| `SHA256SUMS.txt` | 发布附件 SHA-256 校验值 |

模块沿用原发布证书；同项目、同签名内置版通常可以覆盖升级。官方地图与内置版签名不同，切换前先备份配置与个人数据，卸载会清除应用数据。模块版与内置版选择一种，不要对内置地图重复启用外部模块。

**百度更新后请强制停止并重新打开一次**，以替换旧页面脚本。腾讯底栏逐项设置也需重新打开地图。高德国内版与 Play 版包名相同，只能装一个；Play 包不能只安装 base.apk，可用拆分包安装器，或在解压目录执行：

```sh
adb install-multiple -r base.apk split_config.arm64_v8a.apk split_config.xxxhdpi.apk split_config.zh.apk
```
