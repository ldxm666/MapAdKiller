## 导航信息栏

- 设置路径：MapAdKiller 设置 → 地图 → 导航信息栏大小（横屏）。模块独立设置页和内置悬浮面板使用同一项配置 `navi_info_percent`。
- 范围 100%–200%，每档 10%，默认 100%。滑动松手保存，已打开的导航页同步刷新，不要求重启进程。
- 横屏等比例放大顶部转向图标、距离、路名和同一卡片内的车道提示。100% 恢复原生变换；竖屏保持原生大小。
- 只在驾驶导航基页创建的 AJX 上查找精确 `idTripNaviHeaderContainer`，不全局缩放页面，不改地图、触摸坐标或其他页面字号。
- 根据屏幕边界及下方原生控件限制有效比例；路口放大图显示期间使用原生卡片布局，结束后恢复选定比例。保留并恢复原生 scale、pivot 及祖先裁剪属性。
- 国内 17.02.0.2010 与 Play 17.02.2.2014 原包中已核对基页回调、AJX 根字段、DOM 查询方法及目标 ID/路口 class；不能据此推断所有其他高德版本均适配。

实现：`AmapNaviScale.kt`、`AmapHooks.kt`、`Config.kt`、`AmapPanel.kt`。独立模块页 `MainActivity.kt` 补齐等间距大于 1 的滑条步进，使该项与内置面板一致。

## 自动巡航

本轮修复，不改变默认触发阈值：

1. 已攒够持续时间但净位移稍晚到达时，保留时间窗口及位移起点，避免不断清零、重新等待完整时长。
2. 连续读到同一个缓存定位点时不刷新位移计时，下一次真实位置更新能正确计算速度；无效数值、坐标不污染判定。
3. 定位速度 hook 先执行原生方法，再读取完成后的速度信息。
4. 官方巡航两个单 boolean 入口在进程启动时安装 hook，每次调用读取最新开关，解决启动时关闭便无法在本进程开启的问题；原生调用异常不重复执行。已在中/Play 原包核对入口。
5. 新版 `amapuri://edog/home` 进入的是 DriveRadar。成功判定同时识别 `isInCruise()` 与 `isInDriveRadar()`，并在包含巡航状态的 `isInNavigation()` 之前复核，避免进入成功后继续重发入口。
6. 「立即测试」先消费一次性标记；后台、已在导航或巡航时跳过，避免打断当前页面。调试速度文件仅在明确开启调试日志时读取。

设置说明已区分两条链路：高德原生巡航按原生判据工作；速度/时间滑条只影响「模块接管·兜底」。模块接管仍默认关闭、12 km/h、8 秒，并保留净位移和抖动容忍。官方开关在下一次原生 setter 调用时应用；若当前页面不再调用 setter，需要重新进入路线结果页，不能把安装 hook 等同于立即布防。
