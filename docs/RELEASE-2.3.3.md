# MapAdKiller 2.3.3

发布日期：2026-11-08 · versionCode **2303** · 对比基线：**2.3.2 / 2.3.2-play**。

本次重点是应用主源码 Kotlin 迁移、设置 UI 重构、高德横屏导航信息栏自定义大小、巡航触发修正，以及三家地图的配置与界面兼容性修复。

## 相比 2.3.2 的变化

### Kotlin 主源码迁移与设置 UI

- `app/src` 从 2.3.2 的 **152 个 Java、0 个 Kotlin**，迁移为 **172 个 Kotlin、0 个 Java**。测试、编译桩及部分工具仍保留 Java；“全面迁移”指应用主源码，不代表整个仓库没有 Java。
- 重构模块 App 与地图内设置面板：统一配色、字重、行高、圆角和间距，采用参考 Miuix / HyperOS 视觉规范的原生 Android View 实现；新增胶囊式导航、分段标签、弹窗及按压/切换反馈。不是 Jetpack Compose 迁移。
- 修复分段控件测量反复触发布局、弹窗标题与动画不一致等问题；百度、腾讯面板按内容计算高度，减少遮挡和空白。
- 修复现代框架服务接口类打包不完整引起的连接问题；修正本地/远端配置的读写优先级和缺省值迁移，保留用户明确设置。
- 修复百度、腾讯关闭悬浮球后冷启动又出现的问题，已保存的关闭状态继续生效。

### 高德：导航、巡航与打车

- **新增横屏导航信息栏缩放：100%–200%，每档 10%。** 可在设置中调整；按可用空间约束大小，兼顾文字和图标，路口放大图显示时恢复原生布局，结束后重新应用缩放。国内版与 Play 版使用各自校验过的锚点。
- **优化自动巡航触发**：修正首次有效位移延后到达时的计时窗口；重复缓存定位不再推进触发计时；调整速度读取顺序，并兼容新版原生巡航状态。官方巡航开关支持运行中更新，一次性探测及时结束，重诊断仅在调试时运行。
- **移除打车面板拖到中间才出现的顶部活动横幅**，同步收起占位；修正打车营销数据字段和活动专区映射。只处理打车首页推广区域，保留上车点、目的地、订单、安全与合规内容。
- 修复内置版覆盖升级后可能白屏的原生库路径/依赖加载问题。
- 增加 17.02 语音搜索兼容选项；首轮展开已验证，重复唤起和完整识别流程仍需继续反馈。

### 百度：工具、通勤与支付兼容性

- 首页工具宫格按原生数据排列为每行 5 项，保留原生点击和入口模型；修复抽屉高度、预览重叠与多余空白，保留原生底部导航。
- 修正“回家/公司”子开关与总开关的联动，恢复开关后可重新显示；沿用原生地址控制器及地址管理入口，不改写收藏与历史记录。
- 支付兼容策略避让官方收银台，减少模块浮层干扰；增加按阶段定位跳转问题的调试信息，不输出账号、订单或支付链接。**目前没有可复现的待支付订单，不能据此宣布微信/支付宝点击无响应已经修复。**

### 腾讯：标注开关真正可恢复

- 完善主页基础标注的隐藏/恢复，兼容引擎稍后创建、引擎替换、搜索返回、冷启动等情况；失败后有限次重试，页面退出取消过期任务。
- 保存原生图层状态后恢复，保留其它图层位及原生隐藏状态，避免成为“一关就再也回不来”的死开关。
- 明确设置范围：当前原生基础标注位会**同时影响 POI、路名和地名**，只在主页应用；丰富/3D 图层分开控制。它不是只隐藏商户、保留所有路名的逐类 POI 过滤器。
- 修正工具栏、收藏入口与设置面板的布局及切换状态。

### 系统卡片 / 灵动岛兼容性

- 撤除对高德桌面卡片服务及卡片初始化、百度通知服务的误拦截；百度桌面广播只匹配明确的标准 action，保留 OEM 扩展 action 和数据。
- **这只是误拦截修正，不是灵动岛完整适配承诺。** HyperOS 实机已确认高德原生导航前台通知存在，但系统灵动岛仍未显示；ColorOS 暂无实机验收，手表联动也未做完整验证。

## 构建与验证

- 模块、三个国内内置包、高德 Play 拆分内置包来自同一套 2.3.3 源码；内置包只裁掉其它地图实现，构建时检查必须保留的功能类、宿主白名单和注入入口。
- 20 组 Android 回归全部通过，共 **5939 项检查**，覆盖打车字段、横幅策略、导航缩放、巡航回放、配置、支付避让、系统卡片策略及腾讯标注状态机等。
- 对发布内置包解出的生产模块另做 7 组、**1030 项检查**，避免只测开发副本；国内/Play 高德的功能 DEX 一致，宿主补丁分别构建和校验。
- 腾讯标注已在免 root 内置版与真正 LSPosed 模块版验证多次开关、冷启动、搜索返回；高德导航已在 2400×1080 横屏模拟导航验证 100% / 160% / 200% 及路口图切换。巡航有定位回放测试，不能替代真实道路、车机和长期行车验证。
- 最终二进制检查版本、签名、ZIP 完整性、注入元数据和宿主内嵌模块；模块沿用原发布证书。详细边界见 [验证说明](VALIDATION-2.3.3.md)。

模块与内置版选择一种使用。官方地图与内置版签名不同，切换前先备份配置和个人数据；同项目、同签名版本通常可以覆盖升级。国内/Play 高德包名相同，只能安装其中一个。Play 包请使用拆分包安装器，或在解压目录执行：

```sh
adb install-multiple -r base.apk split_config.arm64_v8a.apk split_config.xxxhdpi.apk split_config.zh.apk
```
