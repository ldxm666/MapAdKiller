# MapAdKiller 2.3.5

发布日期：2026-11-11 · 模块版本号：**2.3.5 / 2305** · 对比上一版：**2.3.4**。

这次主要解决高德首页留白、滑动和全屏恢复问题，补齐开屏广告拦截，并给高德、腾讯加入按类别显示地图标注的设置。模块版、国内内置版、Play 内置版、百度和腾讯全部同步更新。

## 高德：工具能靠底，收起后也能恢复

- 修复第一次打开时，明明开了设置，功能却没有生效的情况。现在首次进入也会正常加载功能。
- 隐藏部分工具后，其它工具会按剩余位置排列，减少空格和空行。
- 底栏全部关闭后，驾车、公交、步行等首页工具会靠近底部，不再为已经隐藏的底栏空出一大块位置。搜索框和系统手势区域会保留。
- 修复反复上滑、下滑后，面板停在中间、留下空白的问题。
- 修复点击地图进入全屏后，再点击无法恢复，以及工具宫格关闭后再打开只剩搜索框的相关问题。
- 补齐开屏广告的缓存和请求拦截，避免之前下载过的开屏广告再次出现。默认开启；如果你之前手动关闭过，仍保留你的选择。

国内版和 Google Play 版使用同一套功能修复，安装包分别制作。

## 高德、腾讯：地图标注可以按类别选择

可以分别选择这九类标注是否显示：**餐饮、购物、医疗、学校与科教文化、交通、住宿、景点与休闲、金融、生活服务**。

- 高德：先打开“兴趣点”总开关，再调整分类。改完后**强制停止并重开高德**。关闭总开关仍表示全部隐藏。
- 腾讯：分类在主页生效，可在运行中调整；进入搜索、导航后恢复原生标注样式。
- 腾讯“学校与科教”补齐教学楼等教育图标，不只处理学校名称。
- 尽量保留路名和其它正常地图内容。分类依据地图原生样式，通用楼宇、未知图标或特殊运营标注可能保留，不能保证所有地点都能准确归类。

同时修复腾讯部分热更新后，设置看似开启、实际没有生效的问题。

## 百度与模块版

- **百度内置版也同步到 2.3.5**，设置面板显示新版本号，保留上一版我的页独立开关、工具宫格和配置刷新等修复。
- 模块与内置版同步相应地图的修复，继续保留导航信息栏大小调整、自动巡航等已有功能。
- Kotlin 主源码迁移、设置 UI 重构、导航栏缩放是 2.3.3 引入的已有功能，本次不重复算作新增。

## 更新时注意

1. 先备份配置和个人数据。同项目、同签名内置版通常可以覆盖更新；官方版与内置版签名不同，不能直接覆盖，卸载会清除应用数据。
2. 更新后强制停止对应地图，再打开一次。百度需要重开以替换旧页面脚本。
3. Play 包必须四个 APK 一起安装，不能只装 `base.apk`。可用拆分包安装器，或执行：

```sh
adb install-multiple -r base.apk split_config.arm64_v8a.apk split_config.xxxhdpi.apk split_config.zh.apk
```

地图本身的版本号仍是上表中的官方基线；**2.3.5 是 MapAdKiller 的功能版本**，可在模块或地图内设置面板查看。

## 仍需要继续反馈的地方

- 灵动岛：HyperOS 的高德系统卡片仍有未解决反馈，ColorOS 未完成实机验收，本版不承诺全部恢复。
- 百度打车支付：目前没有可复现的待支付订单，不能宣布微信、支付宝点击无响应已经彻底修复。
- POCO F3 / MIUI 14 / Android 13 的安装问题仍需该机型反馈。
- 车机、真实道路巡航及所有系统、地图版本无法在一台手机上全部覆盖。具体测试范围见 [测试记录](VALIDATION-2.3.5.md)。
