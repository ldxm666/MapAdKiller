# MapAdKiller 2.3.6

发布日期：2026-11-14 · 模块版本：**2.3.6 / 23060** · 上一个公开模块版本：**2.3.5.step2 / 23052**。

本模块同时支持高德、百度和腾讯，各地图单独配置。

- 高德首页工具支持长按拖动和上下移动排序，关闭再开保留位置，“更多工具”固定末尾。
- 修复关闭全部内容卡片后，原生工具面板偶尔没有恢复、只剩搜索框的问题。
- 修复打开多个工具却只显示三个，以及“更多工具”图标变成拼图、误带公交角标的问题。带天气卡片的首页最多显示九个普通工具加“更多工具”；关闭它后保留九个普通工具。关闭工具总开关时同步收起整行占位，天气仍可保留。
- 内容区改成“天气卡片”和“推荐与活动卡片”两个开关，兼容旧设置与旧备份。修复天气不出现、只开天气却显示“发布行程”，以及右侧圆形“扫街榜”未隐藏的问题。
- 重新适配高德 Play 17.02.2.2014 的开屏请求和首页入口，配置就绪后重新读取用户保存的选择。
- 新增“强制关闭自动巡航”，按需开启后禁止原生和模块自动触发，保留手动巡航及正常导航；修正切换自动巡航开关后，旧状态可能导致误触发的问题。
- 修复百度精简首页连续点击首页后展开空白的问题。
- 默认隐藏腾讯“新人专属”等悬浮推广，同时清理动画和点击区域，可单独恢复。

安装 `MapClean-lsp-v2.3.6.apk`，在支持现代 API 102 的框架中启用并勾选需要的地图，强制停止地图后重新打开。使用免 Root 内置地图时，不要再给同一地图启用外部模块。

适配基线：高德国内 17.02.0.2010／Play 17.02.2.2014、百度 22.1.20、腾讯 11.7.0（6013）。其它版本需要重新验证。完整说明、内置包和源码见 [主仓库 v2.3.6](https://github.com/ldxm666/MapAdKiller/releases/tag/v2.3.6)，校验值见附件 `SHA256SUMS.txt`。

高德实机检查使用小米 Android 16 / HyperOS 3、官方 Play 加模块；Android 13、ColorOS、无 Root 内置首次安装、真实道路巡航及真实订单支付仍有未完成验证的范围。灵动岛和百度支付不宣称已经全面解决，具体以 [验证记录](https://github.com/ldxm666/MapAdKiller/blob/v2.3.6/docs/VALIDATION-2.3.6-r3.md) 为准。
