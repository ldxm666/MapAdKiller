## 补修与根因

- 天气首页通过 AJX recommendTools 读取工具，旧逻辑只会删除，不补齐已开启工具。现在合并宿主目录，先选择、按 ID 排序，再限制容量；图标、名称、路由和附加字段一起移动。
- choiceTools 在这个首页用于“更多工具”文件夹预览，不能与 recommendTools 填同一份列表。现在只清空首页显示副本的预览，恢复原生图标，消除拼图和公交角标。
- AJX 原生先保留“更多工具”槽位，所以推荐列表最多九个普通工具；关闭“更多工具”后保留这九项，不能再塞第十个形成不支持的十一单元模型。只定位限定 DOM 中的真实绑定，忽略过期绑定，回收独占行高度。
- 原生结束 AJX 渲染时会移走工具面板，退出页面并不会自动接回。现在通过实际 DEX 核对的 initToolBoxPanel 接回原面板，保留隐藏、拖动和父容器归属，不重复添加、不抢其它页面控件。
- 内容区只显示“天气卡片”和“推荐与活动卡片”。feed_other 明确保存后优先，未保存时兼容原榜单、内容流、促销三个值；旧备份可迁移。天气、打车与家／公司入口保持独立。
- 天气流式响应保留序号、结束信号和地图业务；“发布行程”招募卡归入活动推广。右侧圆形扫街榜按原生 template_rank 处理，普通缩放和图层保留。
- 自动巡航嵌套调用曾把模块改写后的请求误记为原生请求。现在用线程内上下文保留最外层原始状态，异常和重放后正确清理；不影响手动巡航。

首页只读取显示副本，对应写回入口有保护，不把补齐后的工具存入宿主原始选择；“更多工具”编辑页仍沿用原生数据。
