## 已实现

- 统一 View 动效时长与弹簧驱动，补齐中断、取消、重复点击、关闭系统动效场景；切换滑块绘制在文字下方。
- 主界面减少重复卡片和说明，恢复用户要求的悬浮底栏胶囊比例；关于页使用模块自己的应用图标。
- 内置设置沿用 Android View、原有配置键和宿主原生功能。配置页的“内置版请在宿主配置”只读提示是有意策略，不能把它误判成开关无法点击。
- 百度宫格在原生 `RoutePanelShortCutUIComponent.updateRow` 分行前过滤原始模型；原生 `ShortCutRow.update` 保留每行 5 列，清除第 6 个重叠预览位。没有新建图标、替换点击监听或手工改格子宽度。删掉已无实现的旧“紧凑排列”设置行，保留旧键用于兼容。
- 百度抽屉按实际可见内容、父子坐标、滚动与原生底部间距测高。同步修正展开位、收起位、peek 与 extendHeight，稳定后重新采样；内容多则保留原生可用范围，内容少则不再拉出整屏空白。
- 零上滑范围下，宫格与通勤组件使用原生完整展示进度，避免原生 collapsed 状态把第三排或右侧地址管理按钮藏掉。
- 百度悬浮球开关修复镜像读取递归与冷启动过早缓存；首个宿主 Activity 提供 Context 后重新读取用户设置。关闭悬浮球后仍可长按“我的”进入设置。

## “设置家”失效的根因与修复

1. `hc_home` 开启时，`ui_home_company` 仍可能关闭。现在子项开启时在同一次 commit 内开启总开关，两处设置 UI 同步显示总开关状态。手动关闭总开关仍保留子项选择。
2. 旧代码在总开关关闭时跳过 `du_trip_address` 组件注册，导致进程内没有原生控制器可恢复。现在保留原生控制器，只控制其显示。
3. 旧扫描器只会隐藏 `home_info`、`company_info` 和“去设置”文字，从不恢复，并永久清零原生管理入口宽度。现在 `BaiduCommute` 统一负责可逆显示，重新调用原生 `initBg` / `selfUpdate`，恢复原生主题尺寸及分隔线，不替换点击监听。
4. 百度 22.1.20 在云端返回多条地址模型时切换为最近地址 Recycler，而不是家／公司入口。现在仅在通勤组件本次原生绑定的读取范围内选择它已有的本地家／公司分支；不修改共享模型、收藏、历史或地址数据。原生异步任务仍负责加载真实地址与设置跳转。
5. 设置项明确区分“回家 / 设置家”“去公司 / 设置公司”“地址管理入口”，避免把后者与家地址的“去设置”误当作同一个功能。
