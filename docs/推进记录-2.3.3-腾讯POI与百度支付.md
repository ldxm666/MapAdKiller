## 腾讯：区分基础标注与富信息

腾讯 11.7.0（versionCode 6013）实际调用链已从原包核对：

```text
TencentMap.setMapAnnotationVisible
  → MapEngine / JNIWrapper.setMapContentVisible
  → mapsdk2.internal.controllers.e.setContentVisible(8, visible)
```

`MapContent_Annotation = 8` 同时包含普通 POI、地名与路名。已有的 `PoiRich / AppPoiRich / BuildingRich / set3DPOIEnable / setLandmarkEnable` 属于其他能力，不能代替普通底图标注；普通立体楼块也不等于 3D POI 或地标。原生子内容开关 0–3 的现场对照没有证明可以实现普通 POI 单独过滤，没有把猜测接口放入生产代码。

设置路径：**地图控件与 POI → 显示主页底图标注（POI 与路名）**，默认显示。

- 关闭同时隐藏普通店名、地名和路名，保留实际道路、地形与建筑；仅主页生效。
- 进入搜索场景恢复原生标注，返回主页重新应用隐藏；不修改搜索结果数据。
- 保留原始 `setContentVisible` 调用及完整 mask；额外只操作 bit 8，避免把 `ALL` 请求改成全图隐藏。
- 自身写入不污染原生请求记录。富信息开关只在已读取或观察到原生值后遮蔽，避免第一次就写入 false、随后错误地把 false 当作恢复值。
- **未完成“只隐藏 POI、保留全部路名”的分类过滤。** 富信息与 3D 开关仍标为实验项，本轮没有完成它们在所有位置、缩放级别的视觉验收；导航页未实际进入复测，主页作用域保护有代码及测试覆盖。

新增 `tmapclean/TmapAnnotations.kt`，修正 `TmapPoi.kt`，设置目录仍由 `Spec.kt` 统一供内置面板与模块页使用。

现场：Android 16 小米 2210132C，腾讯内置版覆盖安装保留数据。验证默认可见 → 面板关闭 → 冷启动仍隐藏 → 原生景点搜索地图显示标注 → 返回主页再次隐藏 → 面板开启即时恢复。不是只看开关写入或 HOOKED 日志。

## 百度：收银台保护与可复测诊断

原包百度 22.1.20（versionCode 1665）的打车收银台经 `ComPayApiImp.requestPloymerPay`、`MapWalletProxy.nuomiPloymerPay` 与沙箱 IPC 进入官方支付 SDK。微信、支付宝的部分 SDK 和微信回调位于 `:SandBoxProcess`。

已做改动：

1. `PaymentUiPolicy.kt` 按已核实的官方 SDK 命名空间排除浮层，覆盖百度 Poly、钱包、微信回调、支付宝及银联等 Activity。此前主进程的 Poly 收银台不在排除范围内；**这是一项兼容保护，未证明它就是此次无响应的原因。**
2. `BaiduPayment.kt` 仅在开启“调试日志”并重启后安装 SDK 观察钩子，记录收银台请求、沙箱分发、微信/支付宝通道、微信 SDK 发送及支付宝 SDK 返回阶段。
3. 完整模块入口补齐百度子进程分发，内层仍只安装支付观察器，首页清理继续跳过子进程。百度精简版转发桩原已保留该分发，已核对两种构建的路径。
4. 调试记录只包含固定阶段、布尔值、微信 API 整数、支付宝四位状态码或异常类型。原始调用恰好执行一次，返回对象及异常原样透传；不修改、重试或发起付款。

未发现本模块改写支付 SDK、全局阻断支付 Intent 的直接证据。对比原厂包与此前内置包，queries、权限及原有 938 项 application 子组件均保留，targetSdk 仍为 33，微信支付回调仍 exported 且在原沙箱进程；不能把“包可安装”或静态组件完整当作支付成功证据。重签名与外部应用校验兼容性也尚未排除，未绕过任何支付平台验证。

真机已验证：调试关闭时正常冷启动且无支付阶段记录；开启后主进程和沙箱进程均出现 `stage=armed`，未调用订单支付。最终百度重建包的内嵌功能 DEX 与真机及直接 DEX 测试使用的版本一致。

### 反馈者复测方法

使用对应测试包，在设置 → 其他 → 调试日志开启后彻底重启百度。由有真实待支付订单的反馈者复现一次按钮无响应，记录发生时间、百度版本和是否内置版/模块版，然后采集以下过滤结果：

```powershell
adb logcat -d -v threadtime -s BMapClean:I "*:S" |
    Select-String 'event=payment_diag' |
    Set-Content -Encoding utf8 '.\baidu-payment-diag.txt'
```

多台设备连接时加 `adb -s <设备序列号>`。只回传过滤后的阶段记录即可，不必提供订单截图、完整 logcat 或支付参数。主进程的录制环形缓冲不会自动包含沙箱记录，因此这里使用跨进程 logcat 过滤。`wechat_send=true` 仅表示 SDK 发送返回 true，不等于付款成功。复现完关闭调试并重启。
