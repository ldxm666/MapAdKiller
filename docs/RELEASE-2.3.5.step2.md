## 2.3.5.step2

- 版本号：`2.3.5.step2`（versionCode 23052）
- 发布日期：2026-11-13
- 适配宿主：高德地图 17.02.0.2010（国内版）
- 上一版：2.3.5（versionCode 2305）

### 修复

- 高德开屏广告：在原有广告请求与缓存判断之外，增加广告素材下载、启动阶段实时请求、图片/视频广告视图、本地已存广告素材四条路径的拦截。
- 高德开屏广告：补充 `AlimamaRequestHolder.sendSplashScreen` 双参数重载的拦截，2.3.5 仅覆盖三参数重载。
- 高德开屏广告：每次启动清理 `files/splash/` 下已下载的素材文件（`i_*`、`v_*`），目录内其他配置不动。

### 变更

- 拦截范围仍由「拦截开屏广告」开关控制，默认开启；关闭后恢复宿主原始行为。
- 品牌开屏页、首页、搜索、地图标注、导航均未改动。
- 百度、腾讯变体本次无功能改动，仅同步版本号。

### 验证

- 环境：Android 16，内置版安装，覆盖升级。
- 冷启动 2 轮：四条路径的拦截全部命中，本地广告素材计数为 0。
- 冷启动耗时 1005 ms / 1032 ms（2.3.5 基线 1533–1643 ms），无白屏、无 ANR。
- 首页、搜索栏、工具行、底栏、天气卡显示正常。

### 已知限制

- 仅验证高德国内版 17.02.0.2010。Play 版 17.02.2.2014 的混淆名尚未核对，暂不建议使用。
- 依赖宿主类名的方法均为精确签名匹配；宿主版本变化后需重新校验锚点。

### 安装

- 模块版：`MapClean-lsp-v2.3.5.step2.apk`
- 免 root 内置版：`Amap-2.3.5.step2-nonroot-embedded.apk`
- 二选一安装；使用内置版时不要再对高德启用本模块。
