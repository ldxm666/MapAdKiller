# 2.3.4 发布验证与同类缺陷审查

本记录用于 2.3.4 发布源码与产物。审查基于 `e9aab757a63b1868dba17b8e4707b5cdf4616781`，测试日期 2026-11-08。

## 已确认的原因与修复

| 原因 | 修复及保护范围 |
| --- | --- |
| 百度旧我的页实现改写共享数据与数组原型，卡片开关相互牵连 | 页面私有渲染列表、原生配置事件；保留 `cardList`/服务器数据/头部，移除旧 MineData/MineJs |
| 设置进程写入成功，宿主进程没有刷新相应已缓存视图 | 百度通勤/工具/我的页和高德首页统一接入配置监听及失效路径，支持批量恢复 |
| 百度隐藏底栏时清空原生触摸监听，无法按点击监听重建语音入口 | 保留原生监听，仅改变本模块拥有的启用/可见状态，重新开启恢复触摸区 |
| 腾讯隐藏首页快捷入口后把两个行高字段清零，开启只改 visible | 保存原生请求值及历史行高，恢复时调用真实 setter，失败保留快照以供重试 |
| 原位删除腾讯宿主缓存的底栏列表、未知新页套用默认 OFF | 在私有副本上选择入口，保留原始列表和顺序；未支持的新页默认保留 |
| 把所有恢复目标强制设为 VISIBLE | 高德工具宫格、腾讯底栏/通勤/信息流仅恢复本模块修改过的原始状态，尊重宿主后续修改 |
| 腾讯反射缓存使用 Android 13 不存在的 ClassValue | 改用弱键/弱值缓存，避免引用宿主类加载器；在 Android 13 实际回归 |
| native 缓存只比较 APK/库长度；JS/STY 缓存可错信修改时间 | 改为内容摘要；相同大小、保留时间戳的更新和等长缓存损坏都纳入测试 |
| 锚点检查工具漏识别 `<init>`，查询失败亦缺少明确判定 | 支持构造器，传播查询失败与准确的请求方法计数；增加 Python 回归 |

腾讯首页行高恢复使用 11.7.0（6013）DEX 验证过的 `MapBaseView.setSeekChipRowHeight(int)`、`seekChipRowHeight`、`lastSeekChipRowHeight` 和 `getSeekParentView()`。百度页面事件使用 22.1.20 DEX 追踪过的 Talos runtime/context 事件入口。未通过猜测扩展全局视图或 JSON 过滤。

## 实机与验收边界

- 高德国内/Play 底栏，以及百度“只打开顶部图标宫格”的此前实机结果已得到用户确认。本轮最终包另验证国内高德、百度、腾讯的安装启动及百度往返页面；最终 Play 包未再次替换手机上的国内版，生产 DEX 回归不能代替这一项 UI 验收。
- 测试 DEX 对真实生产模块的调用，验证功能代码与裁剪结果，不等同于所有官方签名地图的 LSPosed 注入和 UI 验收；不能把此前未通过的外部模块控制宿主测试改写为通过。
- 腾讯底栏逐项设置需要重新打开地图，让宿主重新绑定；整栏开关以及已跟踪的首页组件按刷新入口即时处理。其它 Kuikly 组件遵循原生页面重建时机。
- POCO F3 / MIUI Global 14.0.11 / Android 13 的“套件无效”报告已有标准 ZIP 重打包方案及解析验证，但尚未取得该 ARM 机型的安装反馈。x86 Android 13 的包解析和 native ABI 不匹配结果不等同于 ARM 安装通过。
- HyperOS 灵动岛是否展示、ColorOS 灵动岛及百度真实待支付订单的微信/支付宝跳转，仍缺相应实际验收条件；本次回归没有将它们标为已解决。
- 测试结束后恢复 LSPosed 为原始截图中的“模块关闭、仅勾选腾讯”；移除了测试期间遗留的高德勾选，未覆盖框架数据库。地图原有开关值保留，临时探针已卸载。
