## 二、当前必须知道的三件事

### 1. 内置版全部落后于模块版

| 产物 | 版本 | 是否含最新修复 |
|---|---|---|
| 模块版 `MapClean-lsp-v2.3.3.apk` | 2.3.3 | ✅ 最新 |

| 高德内置版 | 未构建 | — |

**发布前必须重建三个内置版。**

### 2. 有一个已知未修的视觉 bug

配置页分段控件的**白色滑块压住了选中项的文字**（「腾讯地图」被盖住）。
滑块经 `Skin.shadow()` 提到了一层，`segment` 在它下面。修法：给滑块 `setElevation` 降下去，
或把 `segment` 提到滑块之后 `addView`（当前顺序已是这样，但 shadow 的 RenderNode 层级更高）。

### 3. 动效系统未统一（"不够高级感"的真正原因）

时长散布在 140/160/200/240/260/300/320ms，曲线混用 `UiKit.SPRING` / `DECELERATE` /
`CycleInterpolator` / 系统默认，没有 token 表。**继续零散补点收益递减，应先定规范再收敛。**

### 3.1 Kotlin 全量转译

`docs/kotlin-migration-guide.md`。

### 3.2 修的真 bug

| 提交 | 问题 | 根因 |
|---|---|---|
| `bf2e41d` | **框架永远「连接中」**，所有开关读不到远程配置 | `build.ps1` 重构时把 `interface-102.0.0.jar` 从 d8 **输入**列表漏掉（只留了 `--lib`）。它含 `IXposedService$Stub$Proxy` / `$Default`，无字节码直接引用，d8 不会打包 → 运行时 `NoClassDefFoundError` |
| `2d085a8` | **悬浮球关掉后重启又出现** | `FloatingConfig.hasStored()` 对百度/腾讯写死 `return true`，导致 `floatEnabled()` 永远走「读不到→回落默认 true」分支，且 `mirrorPut(true)` 把兜底镜像一起污染 |
| `eeac6f7` | **开关拨一次之后滑块不再动** | `HyperMotion.Driver.start()` 复用被 `cancel()` 过的 `ValueAnimator`；该 animator 在自己的 update listener 里自我 cancel，内部状态停 STOPPED，再 `start()` 有概率不重新排帧 |
| `cffc585` | 配置页分段控件**撑满整页** | `FrameLayout` 内放 `MATCH_PARENT` 高度子 View + 父容器 `WRAP_CONTENT` = 循环测量，退回用剩余空间量 |
| `940dc6f` | `build_variant.py` 完全没跟上 Kotlin 化 | 四处：硬读 `Version.java`、javac 单遍、白名单漏 `$Companion`、桩调 internal 成员名被改写 |

### 3.3 新增能力

**`AmapEdition.kt`（新文件）** —— 高德国内版 / Play 版自动判定。

判定三条（按可靠性）：
1. `installerPackageName == com.android.vending` → Play
2. `versionName` 第 3 段：国内 `17.02.0.x` / Play `17.02.2.x`
3. `versionCode` 号段：Play `1700xx–1701xx` / 国内 `1702xx+`

三条都不中 → `UNKNOWN`，**不猜**。`nativeVariant()` 返回 `null` = 不打 native 补丁。
界面上显示「· 国内版 / · Play 版 / · 版本未知」。

## 四、构建

### 4.1 模块版

```powershell
cd D:\pojie应用\jiesuo\gh\MapAdKiller
powershell -File app\build.ps1
# → output\MapClean-lsp-v2.3.3.apk
```

构建链：**kotlinc → javac 混编**。kotlinc 用 Gradle 8.9 发行版里的
`kotlin-compiler-embeddable-1.9.23.jar`，编译器 classpath 需要 7 个 jar
（缺任一 → `NoClassDefFoundError`）：

```
kotlin-compiler-embeddable / kotlin-stdlib / kotlin-reflect / kotlin-script-runtime
trove4j-1.0.20200330 / annotations-24.0.1 / kotlin-daemon-embeddable
```

**`build.ps1` 里 `$KotlinStdlib` 必须在 `$App = $PSScriptRoot` 之后定义**，否则拼成相对路径，
报「cannot access built-in declaration 'kotlin.String'」。

### 4.2 内置版

```powershell
python tools\build_variant.py --Target baidu `
  --OriginalApk "D:\pojie应用\jiesuo\.agent_work\cache\baidu\22.1.20\base.apk" `
  --OutputDirectory "output\nonroot-baidu-233" `
  --LspatchJar "D:\pojie应用\jiesuo\work\output\交接包\output\.build-tools\lspatch-v1.2-487-release.jar" `
  --SignatureBypass 2
```

`--Target` 可取 `amap` / `baidu` / `tmap`。

原始 APK：
- 高德 `…\cache\amap\1702002010\base.apk`（177,749,534 B）
- 百度 `…\cache\baidu\22.1.20\base.apk`（223,803,224 B）
- 腾讯 `…\cache\tencent\11.7.0-6013\base.apk`（173,494,962 B）

### 4.3 装到设备（MIUI/HyperOS 必看）

`adb install` 会被 `INSTALL_FAILED_USER_RESTRICTED` 拦。必须走 root session API：

```bash

SID=$(cmd package install-create -r -d -g | sed -n 's/.*\[\([0-9]*\)\].*/\1/p')
cmd package install-write $SID base /data/local/tmp/x.apk
cmd package install-commit $SID
```

## 七、架构速查

### 包结构

```
io.github.ldxm666.mapadkiller  高德适配 + 日志漏斗 H / CaptureLog / Perf
io.github.ldxm666.bmapclean    百度适配
io.github.ldxm666.tmapclean    腾讯适配
io.github.ldxm666.mapclean     共享：UI / 设计 token / 配置 / 悬浮窗 / 兼容层
```

变体构建会**裁掉非本厂商的包**并生成桩。百度/腾讯变体裁掉 `mapadkiller`，
高德变体保留全部。

### 两种形态

| | 模块版 | 内置版（LSPatch） |
|---|---|---|
| 判定 | `getFrameworkName()` = `LSPosed` | = `LSPatch` |
| 入口 | `mapclean.MainHook` | 同 |
| 设置 UI | `MainActivity` | `FloatingPanel`（`MainActivity` 被裁） |
| 配置后端 | LSPosed RemotePreferences | 宿主本地 SharedPreferences |

### 设计 token

唯一来源 `mapclean/HyperDesign.kt`（53 个 token × 2 模式）、`Skin.kt`（工厂方法）、
`SquircleShape.kt`（连续曲率圆角，`EXTENSION=1.1` / `CONTROL=0.643`，8 段三次贝塞尔）。
规范文档 `docs/miuix-design-spec.md`。

**禁止**：硬编码 `0xAARRGGBB`、`GradientDrawable.setCornerRadius`。

## 八、踩过的坑（避免重犯）

1. **d8 输入 ≠ --lib**：`interface-102.0.0.jar` 必须作为输入，否则 AIDL 代理类不进 dex。
   验证：`unzip -p app.apk classes.dex | strings | grep 'IXposedService\$Stub\$Proxy'`
2. **`ValueAnimator` 不可复用**：从自己的 update listener 里 cancel 之后，再 `start()` 不可靠。
3. **`MATCH_PARENT` 子 View 不能放进 `WRAP_CONTENT` 父容器**（循环测量）。
4. **Kotlin 块注释会嵌套**：`/*` 出现在 javadoc 里会吞掉整个文件。
5. **Kotlin 续行不能以 `+` 开头**：运算符要留在上一行行尾（本项目有 54 处）。
6. **`zip.entries` 在 Kotlin 里是函数**：必须写 `zip.entries()`。
7. **PowerShell 会吃掉中文括号**：`git commit -m` 带中文括号必须写文件 + `-F`。
8. **`hasStored` 类判断要三态**（读到 / 读到空 / 读失败），读失败时唯一安全动作是**什么都不改**。
9. **中文路径 + `str_replace_editor`**：锚点缩进必须精确，`HyperDesign.kt` 的成员在
   `companion object` 里是 **8 空格**。
