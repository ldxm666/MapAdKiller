## 这是什么

一个 Android 模块。装好之后，地图 App 的**广告、活动、营销信息流、推荐内容**会被关掉，道路、地名、导航这些该有的东西一样不少。

- **两种装法**：免 root 内置版（普通用户，装上就能用）／LSPosed 模块版（已经用框架的用户）。
- **有开关面板**：所有功能都是开关，你决定关哪些，随时可以拨回来。
- **改了立刻看得见**：面板里每一项都标了「开了会怎样」，不用猜。
- **不占资源**：模块自己不创建线程，静置时几乎不产生任何日志。

支持的应用：

| 应用 | 包名 |
| --- | --- |
| 高德地图 | `com.autonavi.minimap` |
| 百度地图 | `com.baidu.BaiduMap` |
| 腾讯地图 | `com.tencent.map` |

> 当前版本 **2.3.1**（versionCode 2301），基于 libxposed **API 102**，最低 Android 8.0。

## 下载

到 [**Releases**](https://github.com/ldxm666/MapAdKiller/releases) 页面下载，两个包选**一个**就行。

| 包 | 文件名 | 适合谁 | 需要 root 吗 |
| --- | --- | --- | --- |
| **免 root 内置版（高德）** | `Amap-2.3.1-nonroot-embedded.apk` | 普通用户，手机上没装框架 | **不需要** |
| **免 root 内置版（百度）** | `Baidu-2.3.1-nonroot-embedded.apk` | 同上，百度地图 | **不需要** |
| **免 root 内置版（腾讯）** | `Tencent-2.3.1-nonroot-embedded.apk` | 同上，腾讯地图 | **不需要** |
| **模块版**（推荐） | `MapClean-lsp-v2.3.1.apk` | 已经在用 LSPosed / Vector 的用户 | 需要框架 |

**一句话区别**：内置版把模块直接并进了地图本体，装完就是成品，代价是包体大、签名变了；模块版是一个几 MB 的小模块，靠框架注入，三个地图共用一份配置。

> ### ⚠️ 别装错包（这是最常见的误用）
>
> | | **模块版** MapClean-lsp-*.apk | **免 root 内置版** map-*-nonroot.apk |
> | --- | --- | --- |
> | 体积 | **约 4 MB** | **约 175 MB** |
> | 需要框架 | **需要** LSPosed / Vector | 不需要 |
> | 会不会动到高德本体 | **完全不动**（只在运行时注入） | **会替换**：包名仍是 com.autonavi.minimap，但**签名变了**（CN=xiawanli） |
> | 卸载后 | 高德还是官方原版 | 需要重装官方高德 |
>
> **root / LSPosed 用户请只装 4 MB 的模块版。** 如果你发现"高德签名被改了"，几乎一定是装了 175 MB 的内置版 —— 它本来就是重新签名的重打包高德。装回去的办法：卸载高德 → 从应用商店重装官方版 → 只安装模块版。

## 快速开始

### ⚠️ 首次使用必读：第一次打开会自动抓一次官方数据

高德的工具宫格、首页卡片、金刚位、底栏这些都是**官方服务器下发**的，模块只能改本地下发结果。
所以第一次打开走的是「**先原样用一次、抓完再启用**」的自动流程：

1. 第一次打开地图：**纯原生**，模块功能全部不生效（这时看到的就是官方原版）。
2. 正常用一下首页 / 搜索 / 我的，模块在后台把官方下发数据抓全（一般 5～10 秒）。
3. 抓完弹窗「✓ 已获取官方数据」：**5 秒后自动关掉高德并重启**，重启后按你的设置生效。
   个别系统会拦截后台自启，没自动打开就点一下桌面图标，一样生效。
   首页 90 秒内还没打开（首次安装有隐私弹窗、网速慢）就自动退出采集、不启用模块，下次打开继续抓。
4. 采集模式下模块功能全关，但**悬浮窗保留**：右上角小球点开就是面板，「首页」页顶部那条红 → 黄 → 绿提示条
   同时也是入口，随时能看到「正在抓取 / 已抓完」。
5. 想重抓：点同一位置的提示条即可。

> 一句话：**第一次打开别急着设置，正常用一下，等弹窗自动重启就好。**
> 跳过这一步，改了没反应不是 bug，是本地还没拿到官方下发数据。

### 免 root 内置版（推荐）

1. 下载 `Amap-2.3.1-nonroot-embedded.apk`（高德免 root 内置版）。
2. **先卸载手机上原有的高德地图**（内置版重新签过名，和官方签名冲突，无法覆盖安装）。
   > 卸载会清掉登录状态和已下载的离线地图，装好重新登录即可。
3. 安装，打开高德地图：第一次是**纯原生**，等它自己抓完数据并弹窗自动重启（见上一节），
   之后**长按底部「我的」标签约 1 秒**，面板就出来了。
   > 装好后第一次点开若提示「高德地图已停止运行」，再点一次桌面图标即可 —— LSPatch 首次解包 177 MB 宿主时偶发的已知现象，只会出现这一次。

不需要 root，不需要 Magisk，不需要 LSPosed，也不需要任何框架。

### 模块版（LSPosed）

1. 安装 `MapClean-lsp-v2.3.1.apk`。
2. 在 LSPosed / Vector 里**启用模块**，并把**需要处理的地图 App 勾进作用域**
   （高德 `com.autonavi.minimap`、百度 `com.baidu.BaiduMap`、腾讯 `com.tencent.map`，勾哪个管哪个）。
3. **重启目标地图 App**（强制停止后重新打开），然后长按底部「我的」标签约 1 秒。

模块版不改动地图安装包，安全软件不会报红，三个地图共用同一份模块与同一套配置。

## 打开面板

> 图：长按底部「我的」标签

**长按底部「我的」标签约 1 秒** → 面板从底部弹出。**再长按一次**即可收起。

- 面板右上角的 **✕** 只关闭面板，**不会**关掉悬浮球。
- 想彻底让悬浮球消失，去 **外观 → 关闭悬浮窗**（见下一节）。
- 关掉之后想再打开：**还是长按「我的」标签约 1 秒**，面板会重新出现。

面板底部有一个**搜索框**，开关太多找不到时直接搜名字。

## 模块版 App 界面

模块版装好后，桌面会多一个 **MapAdKiller** 图标，点开是模块自己的 App。底部四个标签页，左右滑动也能切：

| 标签 | 里面有什么 |
| --- | --- |
| **首页** | 运行状态（版本 / 作用域 / 广告 SDK）、版本更新检查、三张应用卡片（百度 / 高德 / 腾讯，显示推荐版本与本机版本）、底部「赞赏支持」 |
| **配置** | **按应用分别配置**。顶部选应用，下面是该应用的全部开关，按功能分组折叠（如「高德 · 主页标签栏」「高德 · 首页工具宫格」「高德 · 搜索页」「高德 · 省电 / 后台」…）。支持按开关名 / 配置键搜索 |
| **备份** | 把全部配置导出成 `.json` 文件，或从 `.json` 导入还原。换机、重置前先备份 |
| **关于** | 版本信息、检查更新、GitHub 与 Telegram 入口 |

**几个要点**：

- **三个地图共用一份模块**，但**每个地图的开关是独立的** —— 在「配置」页顶部切换应用即可分别调整。
- **分组默认收起**，点分组标题展开。想快速定位就直接用搜索框。
- 每项开关下面都有一行说明，写清楚「开了会怎样」，不用猜。
- **改完要强停对应的地图 App 再重开**才生效（App 底部也有这句提示）。

## 外观设置

「外观」页有 4 个滑块，**拖动时实时预览，松手才保存**，不满意随时拖回去。

| 滑块 | 可调范围 | 默认值 |
| --- | --- | --- |
| 悬浮球大小 | `36 ~ 72 dp` | `46 dp` |
| 悬浮球不透明度 | `30 ~ 100 %` | `100 %` |
| 面板宽度 | `自动` 或 `280 ~ 420 dp` | `自动` |
| 面板不透明度 | `60 ~ 100 %` | `100 %` |

下面还有两个按钮：

- **恢复默认外观**：一键把上面 4 项拨回默认。
- **关闭悬浮窗**：悬浮球和面板都不再出现（适合已经调好、不想再看到球的用户）。

> ⚠️ 关掉悬浮窗之后**不是没法找回**：**长按底部「我的」标签约 1 秒**，面板会重新弹出。

## 省电 / 后台

这一页有 **11 个开关**。语义请先记住一句话：

> **开 = 这个行为已经被拦截（默认全部开启）；关 = 恢复高德的原生行为。**

| 分组 | 开关 | 拦截了什么 | 关掉之后 |
| --- | --- | --- | --- |
| **推送** | 关闭推送长连接 | ACCS 长连接（**省电最多的一项**） | 长连接恢复，待机耗电上升 |
| | 关闭推送消息处理 | 推送消息的分发处理 | 推送消息会被处理，耗电略升 |
| | 关闭推送服务壳 | 推送服务的外壳进程（**激进**） | 推送服务壳恢复常驻 |
| **后台任务** | 关闭周期任务 | WorkManager / JobScheduler 周期任务 | 周期任务恢复调度 |
| | 关闭子进程拦截 | 子进程拦截的**总闸**（排查用） | 一次性放行全部子进程拦截，用于排查「是不是我拦的」 |
| | 关闭桌面小组件刷新 | 桌面小组件的定时刷新 | 小组件恢复刷新，耗电上升 |
| | 关闭云控调度池 | LotusPool 云控调度池 | 云端下发的周期任务恢复 |
| **埋点与广告** | 关闭阿里埋点 Analytics | 阿里 Analytics 埋点初始化 | 埋点恢复上报 |
| | 关闭开屏广告请求 | 开屏广告请求 | 开屏广告可能重新出现 |
| | 关闭广告曝光上报 | 广告曝光上报 | 曝光数据恢复上报 |
| **地图** | 启用第三方标注过滤 | 过滤第三方 POI 标注（**默认就是关闭**，需手动开启） | 不参与拦截；注意**开启后可能影响帧率** |

顶部还有一个 **「一键省电（全部开启拦截）」** 按钮，一次把其中 **9 项**打开
（不含「子进程拦截」总闸和「第三方标注过滤」——前者是排查开关，后者默认就该关着）。

### 两件必须知道的事

1. **本页开关改动后，需要「强制停止 + 重新打开」目标 App 才生效。**
   这样设计的好处是：关闭的项在运行时**彻底不加载**对应实现，**零性能开销**，而不是「加载了再拦掉」。
2. **代价要提前想清楚**：关掉「推送长连接」之后，**行程提醒、活动推送、消息中心、家人地图消息会收不到**。
   想恢复就把那一项拨回「开」，强停重开即可。

## 更新

- **每天自动检查一次**（24 小时节流，不会频繁请求）。
- 有新版本时，面板顶部的**版本胶囊会变红**，并挂一个「**新版本**」小标。
- **每个新版本只提示一次**，不打扰。
- 也可以手动查：**其他 → 检查更新**，四种状态：`检查中` / `有新版本` / `已是最新` / `线上版本未获取`。
- 查到新版本后会出现 **「镜像下载」** 按钮。

**国内镜像优先**：更新检查与下载会优先走国内镜像
（`gh-proxy.com`、`gh.llkk.cc`、`ghfast.top`、`ghproxy.net`、`jsDelivr`），
**没有 VPN 也能正常查到新版本**。

## 更新日志

### 2.3.1（versionCode 2301）

对比基线：2.2.8。本次修 14 个 bug、加 4 项功能。

#### 高德
- **冷启动 6.5 秒 → 1 秒以内**：根因是本模块自己的 hook 无限递归（`k84.f()` → `AmapData.defaultSlot` → 反射回调 `k84.f()`），每层重解析 5.5KB JSON，涨到 `StackOverflowError` 被吞掉才停
- **开屏页恢复显示**：之前误当广告拦截。`SplashActivity` 是 `activity-alias`，那张白底是高德自己的界面
- **官方自动巡航**可强制进入；模块接管的巡航重做进入判据（速度窗口 / 净距 / 位置跳变 / 心跳）
- so 预加载修复重做；非首帧安装器推迟到首帧后 3 秒

#### 百度
- **配置无法保存（三次反馈的顽固问题）**：根因三层叠加 —— 读路径把 LSPatch 只读 remote 永久定案、`DefaultConfig` 因空桩 `service==null` 早退导致默认值灌进 remote、`invalidate()` 不重置后端。已全部修掉，写路径带回读自校验
- **地点详情页 17 类推广位清理**：猜你想搜 / 周边推荐 / 推荐附近 / 在线房源 / 周边小区 / 社区生活 / 热门服务推荐 / 商户招募 / 流量包 / 好车推荐 / 同类好店 / 房产电话 / 房源价格卡 / 本地购房群 / 咨询顾问 / 周边配套 / 大家都在问 / 房价总览。数据层摘卡，不留白
- 面板重排为 6 个 chip；「赞赏支持」点击区放大到 48dp
- 抓取：成功 Toast/通知 + 1.2 秒自动退出；失败不退出可重试

#### 腾讯
- **悬浮球挂载后消失**：原来挂在首启 `WelcomeActivity` 上，页面结束浮层跟着死。改为跟随宿主所有 Activity 并加布局哨兵
- **面板「只读」**：`Vendor.host` 被非地图包名覆盖导致厂商判别失效。加白名单 + 定案不改写
- **配置写进两个存储**：Context 探测统一到「直给优先」，不再同时写 XML 和 lspatch db
- **性能**：首页视图树转储收进 debug（冷启动日志 443~565 行 → 9~14 行，日志量 -80%）；悬浮钩子只在主进程安装（3 → 1）；布局哨兵 250ms 节流。实测地图帧率官方 39.4 / 内置 40.7 fps —— **掉帧不是本模块造成**

#### 三端通用
- **新增服务器公告通道**：远程推送、首次必弹可关闭、自绘浮层（无宿主主题黑边）、入场/退场动画、HMAC 签名校验
- **「检查更新」改从自有服务器读取**，不再依赖 GitHub
- **全新安装即为精简态**：修掉「JSON 缺键 + 兜底硬编码 true」导致的默认全显；新增 `_defaults_rev` 迁移，只填缺失键，不覆盖用户显式值
- `HookGuard` 单 hook 连续失败自动停用；`Perf` 全 hook 计时

#### 已知未包含
- 首页工具面板紧凑排列（原方案会压塌布局，已回退）
- 腾讯 40fps 上限未动（要 hook SDK 帧率限制器，发热/耗电/版本重推，判断为不划算）

### 2.2.8（versionCode 2280）

- **百度路线页「开始导航」消失**：收壳会连带把整条底栏 GONE 掉，且实例被宿主复用后再也不回来。底栏现在不参与收壳。
- **百度面板「只读」误报**：服务没绑上就判死，实际能写。改为先做一次真实写入探测。

## 常见问题

**Q1. 长按「我的」没反应，面板打不开？**
确认你长按的是**底部标签栏里的「我的」**（不是页面内的头像），并且按住**约 1 秒**再松手。
模块版还要确认两件事：框架里模块已启用、目标地图已加入作用域，并且**重启过**目标 App。

**Q2. 顶部显示 `○ 只读 · 需要目标 App 运行中`？**
面板是靠目标 App 的进程读写配置的。把地图**切到前台**（或重新打开一次），状态会变成 `● 已连接 · 可写入`。

**Q3. 显示 `● 已连接 · 写入被拒`？**
说明配置没能写进去。先**强制停止目标 App 再重开**；仍然如此，检查系统是否限制了该应用的后台/存储权限。

**Q4. 我把悬浮球关了，怎么找回来？**
**长按底部「我的」标签约 1 秒**，面板会重新出现，然后去「外观」里重新打开悬浮窗。

**Q5. 开关点了，但界面没变化？**
分两种情况：
- **「省电 / 后台」页的开关**：必须**强制停止并重开**目标 App 才生效（这些项是安装期/启动期门控）。
- **其他页的开关**：多数立即生效；地图上的标注类改动，需要**重新进入一次地图页**。

**Q6. 推送收不到了？**
去「省电」页把 **关闭推送长连接** 和 **关闭推送消息处理** 拨回「关」，然后强停重开。
这是省电的代价，取舍由你决定。

**Q7. 检查更新一直显示「线上版本未获取」？**
通常是网络问题。稍后再试；模块会优先走国内镜像，但首次检查仍需要能访问 GitHub 或任一镜像。

**Q8. 装内置版提示「应用未安装 / 签名不一致」？**
内置版重新签过名，**必须先卸载官方高德地图**再安装。卸载会清除登录态与离线地图。

### 装了内置版之后，高德自己又更新回去了？

内置版是重新签名过的，理论上商店更新不了它；但部分机型的应用商店/高德自更新会**直接覆盖安装官方版**，表现为"模块突然消失了"。

**处理**：在应用商店里把「高德地图」的**自动更新关掉**，或在高德的设置里关闭自动更新。之后重新安装一次内置版即可。

### 面板显示「只读 · 无法写入配置」/ 开关拨了不生效？

说明当前进程里拿不到可写的配置通道。依次尝试：

1. **先打开一次目标地图 App**，再长按「我的」打开面板（首次冷启动时通道可能还没就绪）；
2. 模块版用户：在 LSPosed / Vector 里确认本模块**已启用**，且**作用域包含**对应地图的包名，然后强制停止地图 App 重开；
3. 仍然不行就重装模块。

> 模块会优先用框架的远程配置通道；拿不到时自动降级为**应用进程内的本地配置**（面板右上角会显示「可写入（本地）」）。降级模式下面板的读取、保存都正常，但**少数在启动极早期安装的拦截项可能仍按默认值运行** —— 关掉再重开一次地图 App 即可。

## 已知限制

- 面板的分类标签栏，从**屏幕最右约 160px** 起手滑动不了（系统手势区冲突）。
  绕过办法很简单：**直接点 chip** 就能跳到对应分类。
- **灵动岛 / 手表联动**：如果官方原包上这些功能同样不可用，那属于设备侧配置问题，与本模块无关。
- **首页工具宫格最多两行（10 个）**：高德原生宫格只排两行，**超过就会溢出**（顶到下方「回家 / 去单位」那一行，或被裁掉）。
  想再放更多入口请用「更多工具」，不要硬塞第三行。
